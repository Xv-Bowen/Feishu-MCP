# 故障排查

先区分：网络/平台入口、MCP 协议、客户端许可、飞书 token scope、资源权限、目标状态。不要把所有错误都当作连接失效。

| 现象 | 排查与处理 |
|---|---|
| 页面或外部发现返回平台 403/登录 HTML | 外部客户端无法访问整站私有入口；确认可访问的 HTTPS 入口与 `CLIENT_MCP_PUBLIC=true`，保留应用 OAuth |
| 回调失败、`invalid_state` / `invalid_grant` | 回调精确匹配当前 `SITE_ORIGIN`；不要重复使用已消费授权码；配置变化后从连接页重新开始 |
| `99991679` | 用户 token 缺少所需 scope；检查原始 `msg` 和 `missing_scopes`，开放平台开通/发布，再让该用户重新授权。单纯重试旧 token 无效 |
| 读取可用、写入被客户端拒绝 | 检查客户端 `feishu.write`、飞书编辑权限和本次明确操作指令；客户端拒绝不等于飞书 API 调用失败 |
| 删除工具要求先读元数据 | 安全核对需要标题/版本/hash；确认 `drive:drive.metadata:readonly`，按工具 schema 填写，不跳过校验 |
| `1069302` 回复评论参数错误 | 查看调用参数、评论类型、content/elements 结构与资源 ID。不要仅凭错误码认定“全文评论不能回复”；以当前实现与最小复现核对 |
| 删除最后一条回复后评论消失 | 使用完整评论列表回查确认目标不存在。`1069301` 本身不应无条件视为删除成功；本实现结合所有评论状态与完整分页确认 |
| `1770003` | 已删除文档的状态；避免误报“重连账号即可修复” |
| `1310249` / `1310214` | 电子表格已删除 / 未找到。实现会按状态分类，不沿用泛化网络错误 |
| 多维表格 `1002` | 可代表不存在或不可访问；结合上下文和已成功删除回执判断，不能只凭此码断言已删除 |
| 元数据仍返回标题，但文件在回收站 | 元数据可滞后或仍可读；查看额外可访问性验证。无法证明时返回 `unknown`，不能把它当作存活或删除成功 |
| `verification_required` / `write_status_unknown` | 先回查目标与原 request_id 回执；不要换 UUID 重复删除/写入。失败或不完整回查不能报 verified |
| 群公告/机器人读不到 | 检查是否内部群、群成员、机器人所在群、独立应用权限及 API 范围；外部群限制不能由服务器强行解决 |
| `resultType` / `ttlMs` / `cacheScope` 缺失 | 确认运行的是本仓库完整 MCP 路由，不是旧网关或旧部署；新版结果字段与官方 schema fixtures 有回归验证 |
| 服务已新增工具，客户端仍旧数量 | Sites 重新发布关联插件；手动 ChatGPT 连接刷新工具；Claude 连接器重新连接并新开对话。不要承诺旧会话即时热更新 |
| 导入/导出任务未完成 | 先创建任务再按票据查询；注意文件类型、大小、上游异步状态和权限。导出创建本身仍可能是写入工具 |
| 规则没有定时执行 | 规则保存不等于后台调度；配置支持的客户端自动化/外部定时调用 |
| `node:sqlite` 或编译错误 | 使用 Node 22.13+；按锁文件安装固定 pnpm；不要漏掉 `build/`、类型声明、SQL 或依赖 |

## 安全复现

用新建的可删除测试资源，在一个账号完成“读前状态 → 用户明确授权 → 操作 → 完整回查”。保存已脱敏的工具名、错误码、HTTP 状态与结果结构；不要粘贴 token、真实群聊正文或文档内容到公开 Issue。

本项目保留飞书经过脱敏的原始说明与缺失权限线索。错误码映射应附 API 上下文；“未知”比错误宣称成功更可靠。
