- 公开站点域名和公共 API 域名按作者要求保留；README 提供现有公开站点链接，部署变量仍需填写自己的地址。域名本身不作为私人凭据。
- 基于已知原部署标识/文档链接/个人邮箱等进行逐文件字节匹配：未发现残留。
- 枚举 URL 主机、邮箱、飞书应用/用户/群标识与硬编码 credential 候选，复核为公共服务、协议标准或合成测试数据。测试中的 `example.*`、`sites.test`、合成飞书 ID 和固定 synthetic token 不是真实凭据。
- 品牌图片替换为原创图标；PNG/ICO 无 EXIF、定位、个人头像或文件路径元数据，SVG/Base64 图标源码可检查。
- Git 提交使用 GitHub noreply 隐藏邮箱。源码与配置不包含个人邮箱、私人签名或原仓库 remote 配置。公开历史在发布时另行核对。
- `.env.example` 只含无效占位值/空值，已加入 ignore 例外；其他环境文件、数据库、日志与依赖目录默认忽略。

自动扫描不是对任意未知隐私的数学保证；这里报告的是所列范围、规则与人工复核结果。后续贡献、部署配置或日志不在本次快照保证内。
